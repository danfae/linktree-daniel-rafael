# Linktree botânico

Página de links responsiva feita com HTML, Tailwind CSS e estilos próprios.

## Arquivos

- `index.html`: conteúdo da página e configuração do Tailwind via CDN.
- `styles.css`: cores, ilustrações, responsividade e estados de interação.

## Personalização

Edite o nome, a descrição e os destinos dos links em `index.html`. O botão “GitHub do projeto” já aponta para este repositório.

Abra `index.html` no navegador para visualizar a página. É necessária uma conexão à internet para carregar Tailwind CSS e as fontes externas.
